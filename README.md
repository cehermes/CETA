# CETA — Chicken Eater Trading Assistant

用类似 ComfyUI 的**节点工作流**，管理股票交易的"计划 → 执行"流程。纯本地运行，数据不出你的电脑。

每个节点是一张卡片：填几个价格，它就算出盈亏比、止损/盈利金额、保本价、浮盈锁定率等，并能一键生成一张**带提醒的结果图片**。图片里嵌着整个工作流，把图片（或保存的 JSON）拖回页面就能还原。

> **免责声明**：本工具只是交易计划的辅助计算与记录工具，**不构成任何投资建议**。保本价的定义：股价等于该价格时，整个投资（含已卖出部分）的总盈亏为零；**不考虑交易成本和除权除息**。使用者对自己的交易决策负全部责任。

## 8 个节点

| 阶段 | 计划节点 | 执行节点 |
|---|---|---|
| 开仓 | 开仓计划 | 开仓执行 |
| 保本（减仓到保本） | 保本计划 | 保本执行 |
| 出货（减仓移损） | 出货计划 | 出货执行 |
| 加仓（经历过保本/出货后） | 加仓计划 | 加仓执行 |

约定：**计划节点**用来算"该怎么做"，**执行节点**用来记"实际做了什么"（实际成交价、数量等由你填）。

## 快速开始（Windows）

1. 准备 Python 3（任选其一）：
   - 安装 [Python 3](https://www.python.org/downloads/windows/)，安装时勾选 *Add python.exe to PATH*；
   - 或下载 *Windows embeddable package (64-bit)*，解压到本文件夹下，命名为 `python_embeded`（里面直接是 `python.exe`）。
2. 双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:8199/`（端口被占用会顺延，以黑色窗口里显示的网址为准）。用 **Chrome 或 Edge**。
3. 用完关闭黑色窗口即可停止。下次启动，上次的工作流会自动恢复。

只用 Python 标准库，不需要 `pip install` 任何东西。

> 没装过 Python 的电脑上 `python_embeded` 是否解压即用，目前**没有验证过**；其他操作系统也没有测试过（直接运行 `python server.py` 理论上可行，但"打开 output 文件夹"按钮只在 Windows 有效）。

## 怎么用

- 点顶部的 **＋ 节点名** 新建节点；拖节点标题移动；拖空白处平移画布；滚轮缩放。
- 每个参数行左右各有一个圆点：**从一个圆点拖到另一个圆点就连线**（左边入、右边出），双击连线删除。接了线的输入会变灰（由上游传入）。
- 圆点颜色：**蓝色 = 建议手动输入**，绿色 = 数字参数，黄色 = 文字参数（股票名称），灰色 = 计算结果（只有右边一个点）。
- 点节点标题左边的小圆点可以折叠节点。`Ctrl+Z` / `Ctrl+Y` 撤销与重做。
- 参数不合理时，节点会显示红字原因；计算结果里的【重要提醒】会显示在图片标题右侧（黄色）。
- 节点底部：
  - **保存为图片**：生成 PNG，存到 `output\<股票代码>\`，文件名形如 `000001_加仓计划_20261027_102957-1132.png`（日期_图片上显示的时间-保存时分）。
  - **保存为json**：把整个工作流存成 JSON，位置和命名同上。
- **把 PNG 或 JSON 拖进页面**，会在新标签页里还原工作流。
- 每个股票文件夹里会自动建一个 `归档` 子文件夹，你可以手动把旧文件放进去。
- 顶部"打开 output 文件夹"按钮直接打开保存位置。

## 文件夹结构

```
NodeFlow/
├── web/index.html     前端（全部界面与计算都在这一个文件）
├── server.py          本地服务（保存图片/JSON、自动保存工作流）
├── start.bat          启动脚本
├── output/            生成的图片和 JSON（按股票代码分文件夹，不入库）
├── user/state.json    自动保存的工作流（不入库）
├── python_embeded/    可选的内置 Python（里面只有一个说明文件）
├── examples/          示例工作流（PNG/JSON 拖进页面即可还原）
└── docs/DEVELOPMENT.md  开发文档
```

## 给接手的 AI（让 AI 继续迭代这个项目）

如果你是被用户叫来修改或扩展本项目的 AI，请**按这个顺序**读：

1. `docs/DEVELOPMENT.md` —— 架构、8 个节点的参数/公式/行序、图片约定、价格刻度新版面方案、`VER` 与迁移规则、已知问题、**与使用者的协作约定（第 12 节，务必遵守）**。
2. `CHANGELOG.md` —— 版本历史与"未来迭代"清单。
3. `web/index.html`、`server.py` —— 代码本身（前端约 50 KB，可整体读完）。

开始改动前请记住：
- 项目当前处于 **v1.0 功能冻结**状态；用户没有提出新需求之前只修 bug。
- 只做用户提的事，不擅自调整参数位置、名称、默认值、颜色。
- 改了存档字段或默认连线，必须 `VER` +1 并新增 `migrateN`。
- 每次改动后交付完整的 `web/index.html`（必要时 `server.py`），并更新 `docs/DEVELOPMENT.md` 与 `CHANGELOG.md`。
- 沙箱里没有浏览器时，用 Node + 最小 DOM 桩测试计算、连线、迁移（思路见开发文档第 10 节），并**如实说明视觉效果未在真实浏览器验证**。
